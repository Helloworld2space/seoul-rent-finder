Rent.li의 기능별 사용법

동네 리포트 계산기 간단검색 오늘의 전/월세 평균 ← 탐색기로 돌아가기

1. 실거래 조회

  • 지역 탭 — 서울 / 경기 / 인천을 전환하면 해당 지역의 구 목록이 나옵니다. 구를 여러 개 선택할 수 있고, 하나도 선택하지 않으면 현재 탭 지역 전체를 조회합니다.
  • 주거 유형 — 아파트 · 연립다세대(빌라) · 단독다가구 · 오피스텔을 다중 선택합니다. 단독다가구는 건물명·층 정보가 공공 데이터에 없어 "단독/다가구"로 표기됩니다.
  • 조회 기간 — 최근 1~12개월의 계약 신고 자료를 가져옵니다. 지역·기간·유형을 넓게 잡을수록 조회가 느려집니다.
  • 여기 나오는 데이터는 계약이 완료되어 신고된 실거래 기록입니다. 현재 나와 있는 매물이 아닙니다 — 시세 파악과 후보 지역 좁히기에 사용하세요.

2. 필터 · 정렬 (재조회 없이 즉시 반영)

  • 유형 — 전체 / 전세 / 월세. 월세 금액이 있으면 월세로 분류됩니다.
  • 보증금 — 만원 단위 범위. 예: 3억 = 30000.
  • 면적(㎡) / 평수 — 원하는 단위로 범위를 입력하세요. 둘 다 입력하면 두 조건을 모두 만족하는 거래만 남습니다. (1평 ≈ 3.3㎡)
  • 정렬 — 계약일·보증금·면적 기준 오름/내림차순.
  • 조건을 바꿔도 서버를 다시 부르지 않아 즉시 반영됩니다. 지역·기간·유형을 바꿀 때만 조회를 다시 누르세요.

3. 지역별 평균

  • 결과 위의 표에서 구별 전세 평균 보증금 / 월세 평균 보증금·평균 월세와 건수를 보여줍니다.
  • 현재 적용된 필터 기준으로 계산되므로, 필터를 바꾸면 평균도 함께 갱신됩니다.

4. 각 거래의 액션 버튼

  • ★ — 관심 거래로 저장/해제합니다. 구글 로그인이 필요합니다.
  • 지도 — 네이버 지도에서 해당 단지를 검색해 사진·거리뷰를 볼 수 있습니다.
  • 매물찾기 — 네이버 부동산 검색 페이지로 이동해 그 단지·동네의 현재 매물을 찾아볼 수 있습니다.
  • 중개업소 — 해당 동네에서 영업 중인 부동산 중개업소의 상호·주소·전화번호를 보여줍니다(서울 열린데이터 기준, 서울만 지원). 첫 조회는 몇 초 걸릴 수 있습니다.
  • 인테리어 — ROOM TWIN 3D가 새 탭으로 열리며, 해당 거래의 평수로 방 크기가 미리 설정됩니다. 가구를 배치해보고 AI 추천도 받아보세요.

5. 로그인 · 관심 거래 · 맞춤 검색

  • G 구글 로그인 — 구글 계정으로 로그인하면 관심 거래가 계정에 저장되어 어느 기기에서든 유지됩니다. ROOM TWIN 3D와 같은 계정을 씁니다.
  • ★ 관심 목록 — 저장한 거래를 한곳에서 보고, 삭제하거나 지도·매물찾기·인테리어로 바로 이동할 수 있습니다.
  • 맞춤 검색 — 저장한 거래들을 분석해 자주 저장한 지역(최대 5곳), 주거 유형, 전/월세 성향, 보증금·면적 범위(±15%)를 자동으로 검색 조건에 채우고 바로 조회합니다. 관심 거래를 1건 이상 저장하면 활성화되고, 많이 저장할수록 정확해집니다.

데이터 출처

  • 실거래가: 국토교통부 부동산 거래신고 자료 (공공데이터포털 공식 API)
  • 중개업소: 서울 열린데이터광장 부동산 중개업소 정보 (영업중만 표시)
  • 모든 데이터는 공식 공개 API로만 수집합니다.
